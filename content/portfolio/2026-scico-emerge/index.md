#### Abstract

Aggregate computing has been studied for over a decade and is supported by multiple programming
frameworks, proving suitable for simulating applications in challenging domains such as
smart cities and robot swarms. Project Emerge is a toolchain for practical multi-robot
demonstrations based on aggregate computing principles, validated through a public, live,
interactive demo at a European Researchers' Night event. Using a camera system and ArUco
markers for localization, we show how the demonstrator coordinates mobile robots to form
spatial patterns.
